# 种子库 seedbank

写小说用的素材库。卡片 + 双向链接 + 草稿状态位 + 一致性检查。纯前端，数据只存在你自己的浏览器里。

在线地址：https://01dingzu.github.io/seedbank/

## 它有四件事是通用笔记软件做不到的

1. **记入成本接近零** —— 打开就是一个输入框，写完 `Ctrl/⌘ + Enter` 就存，不用先选分类。
2. **双向链接 + 反向引用** —— 正文里写 `[[标题]]` 即链接；点一个还不存在的链接，会直接把那张卡建出来。
3. **状态位** —— 每章稿子可以随手记状态位（`电量 35`、`伙伴_锄 信任 3` 之类），以后做分支剧情时是现成的数据源。
4. **一致性检查** —— 唯一"程序能做而人做不了"的功能：
   - 人物被写丢（连续 3 章以上没出现 / 从头到尾没出现，会一并匹配「别称」）
   - 禁忌冲突（卡片「禁忌」字段里的关键词出现在正文里）
   - 没用上的素材（设定 / 场景 / 片段类卡片，标题从未在正文出现）

## 五个页面

| 页面 | 用途 |
| --- | --- |
| 速记 | 一句话灵感，回车即存 |
| 卡片 | 设定 / 人物 / 场景 / 片段四类，字段自定义，可贴图 |
| 章节 | 写正文 + 随手记状态位 |
| 一致性 | 上面三类提示，点提示直接跳到出问题的卡片或章节 |
| 备份 | 导出 zip（Markdown + JSON + 参考图）、导入、载入示例、清空 |

## 两个字段值得特意用起来

- **别称**：逗号分隔。一致性检查会连别称一起匹配，正文写简称也算出现过。
- **禁忌**：逗号分隔的关键词。正文里一出现就报警。

## 数据在哪

全部在浏览器 `localStorage`（图片在 IndexedDB）。没有后端、没有账号、不上传任何东西。
**换浏览器 / 清缓存会丢**，所以别忘了定期在「备份」里导出 zip。

可安装为 PWA（浏览器地址栏的"安装"按钮），装完离线可用。

## 本地开发

```bash
npm install
npm run dev      # 开发
npm run build    # 类型检查 + 构建到 dist/
npm run preview  # 预览构建产物
```

技术栈：React 18 + TypeScript + Vite + Zustand。

## 脚本

`scripts/smoke.mjs` —— 用 CDP 跑的冒烟测试（21 项断言）。需要先起 `npm run preview`，
然后：

```bash
SMOKE_URL=http://127.0.0.1:4173/ node scripts/smoke.mjs
```
